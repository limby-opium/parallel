## 📋 Описание проекта

В данной лабораторной работе реализована программа для перемножения двух квадратных матриц с использованием **OpenMP** для параллельных вычислений на C++. Проведён бенчмарк производительности при различном количестве потоков, выполнена автоматическая верификация результатов через Python/NumPy, и построены графики ускорения.

---

## 🚀 Что выполняет программа

1. **Генерация** двух квадратных матриц случайных вещественных чисел заданного размера
2. **Параллельное умножение** матриц с помощью директив `#pragma omp parallel for collapse(2)`
3. **Бенчмарк** — замер времени при `1`, `2`, `4` и `8` потоках
4. **Верификация** — автоматическая проверка результата через `numpy` (`A @ B`)
5. **Сохранение** результатов в файлы и построение графиков

---

## 📂 Структура проекта

```
project/
├── include/
│   └── matrix_utils.h      # Утилиты: генерация, умножение, чтение/запись
├── src/
│   └── main.cpp             # Точка входа, бенчмарк, OpenMP-параллелизм
├── result/                  # Выходная папка (создаётся автоматически)
│   ├── A.txt                # Исходная матрица A
│   ├── B.txt                # Исходная матрица B
│   ├── result.txt           # Результат перемножения C = A × B
│   ├── timings.csv          # Данные времени для графиков
│   ├── performance.png      # График: время vs размер матрицы
│   └── speedup.png          # График: ускорение потоков
├── verify.py                # Автоматическая верификация (Python + NumPy)
├── plot.py                  # Построение графиков (matplotlib)
├── benchmark.sh             # Полный прогон по размерам
├── Makefile                 # Сборка и запуск
└── README.md                # Данный отчёт
```
