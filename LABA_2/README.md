## 3. Описание алгоритма

### 3.1. Последовательное умножение

Классическое умножение двух квадратных матриц $A$ и $B$ размера $n \times n$
вычисляется по формуле:

$$C[i][j] = \sum_{k=0}^{n-1} A[i][k] \cdot B[k][j]$$

Общее количество операций (умножений + сложений):

$$V = 2n^3 - n^2$$

Сложность алгоритма — $O(n^3)$.

### 3.2. Параллельное умножение (OpenMP)

Используется директива:

```cpp
#pragma omp parallel for collapse(2)
for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++) {
        double sum = 0.0;
        for (int k = 0; k < n; k++)
            sum += A[i][k] * B[k][j];
        C[i][j] = sum;
    }
```
