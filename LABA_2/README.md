##  Что выполняет программа

- Генерация двух квадратных матриц случайных вещественных чисел заданного размера
- Параллельное умножение матриц с помощью директивы `#pragma omp parallel for collapse(2)`
- Бенчмарк — замер времени при **1, 2, 4 и 8 потоках**
- Верификация — автоматическая проверка результата через Python/NumPy (`A @ B`)
- Сохранение результатов в файлы и построение графиков
